Store Coordinate Batch for Chrome · v5.0

1. Load your LibreOffice sheet

Choose the .ods file you work in (a .csv or .xlsx also works). Required: Store code. Latitude and Longitude are required only for coordinate changes. Business name, Street address (+ line 2 and line 3), Locality, Administrative area and Postal code are used for the Business Manager check. Your original file is never changed.

    2. Run

    Be signed in to business.google.com in this Chrome profile (keep your business list open in a tab, it is only used to remember the address). When you start, the extension opens its own separate Chrome window in the background and does all the work there - you can keep using your other windows. Do not minimise that window and do not cover it completely with other windows (leave a corner of it visible, or drag it to a second screen), otherwise Chrome may freeze its page. Do not click, scroll or zoom inside it while it works. Allow location for business.google.com if Chrome asks.

    Address details include street address lines, locality, state and PIN code. Business names are checked only. Option 2 visits each ATM once: checks its address, saves coordinates, then finishes. No automatic second pass. Options 1 and 3 finish updates, then run a read-only check pass. Delayed display updates never trigger another Save.

    Stores that need verification, will not open, or are marked duplicate are skipped and listed in the Excel file. If one store code belongs to several businesses, all of them are processed and marked in the Excel file.

    Use the floating Stop / Start button on the Business Manager page to suspend and resume the current ATM. Switching tabs inside the background window pauses it; clicking other windows does not. You can also press Stop / Start in this dashboard.

    4. Download the result as Excel

    One click gives you yourfile_updated.xlsx: all your original columns plus Run option, Coordinate status, the five checks (Business name check, Address check…), Address / Locality / Admin area / Postal code update (what was changed and the old value), Update summary, Skip reason and Shared store ID. Store IDs that belong to several businesses are marked in blue and listed one per business on a second sheet. Your original file is never changed.
